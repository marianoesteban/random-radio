# Changelog

All notable changes to Random Radio will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## 0.1.0 - 2026-08-20

Initial release.

- Random live-radio discovery with automatic retries for unavailable streams.
- Custom playback controls with remembered volume and mute preferences.
- Station details with country flags, country names, and homepage links.
- Locally stored favorites with a 500-station limit and JSON import and export.
- Restoration of the last-played station across browser sessions.
- Light and dark themes based initially on the system preference.
- Responsive, keyboard-accessible layouts for desktop, tablet, and mobile devices.
